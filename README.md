# Student-performance-analysis-system
A Python-based Student Performance Analysis System to analyze student academic performance and generate insights from academic data.
The system helps users organize student marks, calculate averages, assign grades, and identify academic strengths and weaknesses.

🚀 Features

Student Record Management: Store student names, enrollment numbers, and subject marks.

Marks Calculation: Automatically calculate total marks and student-wise averages.

Subject Analysis: Calculate subject-wise averages to understand overall performance.

Grade Assignment: Assign grades based on calculated average marks.

Performance Comparison: Identify the highest and lowest performing students.

Weak Subject Identification: Highlight subjects with comparatively lower performance.

Performance Summary: Generate a summary of student marks, grades, and academic performance.

Input Validation: Handle invalid inputs and marks outside the valid range.
